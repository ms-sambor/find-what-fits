# Find What Fits

**Find What Fits** is a collection of simple, free web tools for planning, remembering, focus, time, and routines, with an emphasis on tools that work across devices.

The toolkit is designed to help users explore supports based on what they need help with rather than on a specific diagnosis or disability.

## Features

- Browser-based tools
- No student account required
- Tools organized by support need
- Search and filtering
- Plain-language descriptions
- Read-aloud support
- Colorless display option
- Keyboard-accessible controls
- Responsive design
- Atkinson Hyperlegible typeface
